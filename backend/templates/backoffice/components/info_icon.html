Pressing the button shows the text in a bubble and announces it through a live region; pressing it again, Escape, a click elsewhere or tabbing away hides it. See src/js/components/info-toggletip.js. Args: text: The sentence explaining whatever the icon sits beside. id: Optional id for the text, so a control can point aria-describedby at it. about: What the text explains, for the button's name: "More about Registrations".

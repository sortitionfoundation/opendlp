Args: title: card heading — the target category name, e.g. "Gender". segments: list of dicts, each {"label": str, "count": int|float, "color": , "display": }. Default false: slices sit flush. legend: draw Chart.js's built-in per-card legend (default true). Pass legend=false when a row of cards shares one pie_chart_legend() rendered by the surrounding layout — every card in a dashboard section has the same value labels, so one legend serves the row and the pies stay full-size.

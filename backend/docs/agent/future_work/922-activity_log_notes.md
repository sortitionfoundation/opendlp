# Activity Log

Shortcut epic sc-891, data/service layer story sc-922.

## What currently has some sort of log in the database

- selection records
- comments/records of change on individual respondents (including creation via import or registration)
- auto-export gsheet - sc-1029
- registration page changes
- review code for other things
  - any updates to respondents
  - anything done in a celery task, where users might not see it happen

## What we'd want to add

- All changes to a project - manual and automated
